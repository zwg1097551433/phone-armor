## 一、一键部署（联网）

```sh
mkdir -p /root/phone-armor && cd /root/phone-armor && node -e "fetch('https://raw.githubusercontent.com/zwg1097551433/phone-armor/main/vanilla.sh').then(r=>r.text()).then(t=>require('fs').writeFileSync('vanilla.sh',t))" && sh vanilla.sh --with-inject
```

`--with-inject` 会同时放入本仓库的注入正文（否则原版没有 `prompt-inject.md`，`apply` 会报「提示词和规则集都是空的」）。

**跑完重启**：`设置 → 本机引擎 → 停止 → 启动`

## 二、分步部署（推荐，出问题好定位）

六步，一条一条来。

### 步骤 1：确认环境

```sh
node -v
ls -d /opt/dsh/node_modules/@deepseek-ai
ls ~/.dsh/profiles/web/package.json
```

三个都要有输出。缺哪个先解决哪个。

### 步骤 2：下载包

```sh
mkdir -p /root/phone-armor/payload && cd /root/phone-armor/payload
```

```sh
node -e "fetch('https://github.com/kingcharleslzy-ai/dsh-purge/releases/download/v1.6.91/dsh-purge-community-1.6.91.tgz').then(r=>r.arrayBuffer()).then(b=>require('fs').writeFileSync('dsh-purge-community-1.6.91.tgz',Buffer.from(b)))"
```

### 步骤 3：校验（必须做）

```sh
sha256sum /root/phone-armor/payload/dsh-purge-community-1.6.91.tgz
```

必须等于：

```
ae22bb7d1ac1e055102c8fbd24cf2eedc282a94bfa3fb09e7ab91226fc033058
```

不一致 → 重新下载，**不要继续**。

### 步骤 4：解包落位

```sh
cd /root/phone-armor/payload && mkdir -p unpack && tar -xzf dsh-purge-community-1.6.91.tgz -C unpack
```

```sh
cp -a /root/phone-armor/payload/unpack/package ~/.dsh/profiles/web/node_modules/dsh-purge-community
```

### 步骤 5：登记到 profile

```sh
node -e "const f=require('os').homedir()+'/.dsh/profiles/web/package.json';const fs=require('fs');const o=JSON.parse(fs.readFileSync(f,'utf8'));o.dsh=o.dsh||{};o.dsh.profile=o.dsh.profile||{};const b=o.dsh.profile.bundles=o.dsh.profile.bundles||[];if(!b.includes('dsh-purge-community'))b.push('dsh-purge-community');fs.writeFileSync(f,JSON.stringify(o,null,2)+'\n');console.log('bundles:',b)"
```

### 步骤 6：放注入正文 + apply

**注入正文**（原版没有，必须自己放）：

```sh
cp /root/phone-armor/payload/prompt-inject-full.md ~/.dsh/prompt-inject.md 2>/dev/null || cp /root/phone-armor/payload/prompt-inject.md ~/.dsh/prompt-inject.md
```

**打补丁**：

```sh
DSH_BASE=/opt/dsh/node_modules/@deepseek-ai node ~/.dsh/profiles/web/node_modules/dsh-purge-community/bin/dsh-purge.js --apply
```

**看结果**：

```sh
DSH_BASE=/opt/dsh/node_modules/@deepseek-ai node ~/.dsh/profiles/web/node_modules/dsh-purge-community/bin/dsh-purge.js --status
```

看到 `补丁 N/86 已清洗` 就成。N 应该在 60 上下。

跑完重启引擎。

## 三、完整包本地部署（不联网）

适用于：手机拉不动 GitHub。

### 3.1 从电脑传包到手机

包在本机：

```
E:\deepseek工作区\phone-armor\离线包\dsh-purge-community-1.6.91.tgz
```

传到手机的 `/root/phone-armor/payload/`。传法二选一：

**A. 通过 DSH Web 界面上传**

1. 手机浏览器打开 `http://127.0.0.1:3080/?token=...`（token 从 App 日志找）
2. 新建会话 → 附件上传 tgz
3. 文件落在 `~/.dsh/attachments/` 下


```sh
adb push "E:\deepseek工作区\phone-armor\离线包\dsh-purge-community-1.6.91.tgz" /sdcard/Download/
```


## 四、注入正文说明（原版的关键差异）

**原版不自带注入文本。** `dsh-purge` 只负责打代码补丁，注入正文要用户自己写，放在：

```
~/.dsh/prompt-inject.md
```

没有这个文件时，`--apply` 会报：

```
[ERROR] 提示词和规则集都是空的，必须先添加提示词
```

本文用本仓库提供的两档文本：

| 文件 | 大小 | 内容 |
|---|---|---|
| `prompt-inject-full.md` | 36781 | 5 条执行纪律 + 手机能力边界（推荐） |
| `prompt-inject-core.md` | 30428 | 只有 5 条执行纪律 |

从本仓库下载：

```sh
cd /root/phone-armor/payload && node -e "fetch('https://raw.githubusercontent.com/zwg1097551433/phone-armor/main/payload/prompt-inject.md').then(r=>r.text()).then(t=>require('fs').writeFileSync('prompt-inject-full.md',t))"
```

## 五、自检与排查

### 5.1 补丁状态

```sh
DSH_BASE=/opt/dsh/node_modules/@deepseek-ai node ~/.dsh/profiles/web/node_modules/dsh-purge-community/bin/dsh-purge.js --status
```

输出开头会列：

```
宿主 / surface   web
DSH_HOME         /root/.dsh
插件根 / root    /opt/dsh/node_modules/@deepseek-ai     ← 这行必须有值
注入状态         default
补丁 66/86 已清洗, 0 待清洗
```

### 5.2 注入是否到达模型

```sh
node ~/.dsh/profiles/web/node_modules/dsh-purge-community/bin/community.js probe new
```

会返回一个 nonce，然后发一句话，看模型有没有原样回显。

### 5.3 「注入未成功」怎么判断

手机 B 上出现过"很多注入未成功但破甲自检能返回"的情况。三个检查点：

| 检查 | 命令 | 正常值 |
|---|---|---|
| 注入文件在不在 | `ls -l ~/.dsh/prompt-inject.md` | 存在，>30000 字节 |
| 插件读不读它 | 看 `--status` 的「注入状态」 | 不是 `default` 说明读到自定义文本 |
| 模型档位 | `grep -A6 agent-default-model ~/.dsh/profiles/web/cordis.patch.yml` | `model: deepseek-flash` |

**最可能的原因：模型档位。**

`deepseek-v4-pro` 的对齐强度高，会识破注入文本；`deepseek-flash` 才会照做。

```sh
cd ~/.dsh/profiles/web
cp cordis.patch.yml cordis.patch.yml.bak
sed -i 's/model: .*/model: deepseek-flash/' cordis.patch.yml
sed -i 's/reasoningEffort: .*/reasoningEffort: low/' cordis.patch.yml
```

重启后重测。

### 5.4 tuning.json（原版默认没有）

原版的 `refusalRetry` 默认关闭，`injectPosition` 默认只在头部。补上会明显改善：

```sh
mkdir -p ~/.dsh/dsh-purge && cat > ~/.dsh/dsh-purge/tuning.json <<'EOF'
{
  "boost": true,
  "injectPosition": "both",
  "askNoBlock": true,
  "rewind": true,
  "refusalRetry": true,
  "extraPatches": []
}
EOF
```

重启生效。

## 六、回滚原版

```sh
DSH_BASE=/opt/dsh/node_modules/@deepseek-ai node ~/.dsh/profiles/web/node_modules/dsh-purge-community/bin/dsh-purge.js --revert
```

### 6.2 摘插件

```sh
node -e "const f=require('os').homedir()+'/.dsh/profiles/web/package.json';const fs=require('fs');const o=JSON.parse(fs.readFileSync(f,'utf8'));const b=o?.dsh?.profile?.bundles;if(Array.isArray(b))o.dsh.profile.bundles=b.filter(x=>x!=='dsh-purge-community');fs.writeFileSync(f,JSON.stringify(o,null,2)+'\n');console.log('done')"
```

```sh
rm -rf ~/.dsh/profiles/web/node_modules/dsh-purge-community
```

### 6.3 清注入文件

```sh
rm -f ~/.dsh/prompt-inject.md
```

跑完重启。

## 八、与原版官方安装方式的差异

上游文档推荐：

```
dsh plugin --profile web add <TGZ URL>
```

这条需要手机上有可用的 `dsh` CLI + 包管理器。**本机未验证通过**，所以本文用「解包 + 落 node_modules + 改 bundles」的手动方式，效果等价。

想试官方路径：

```sh
dsh --version
dsh plugin --profile web list
```

能跑就说明可用，可以改用 `dsh plugin --profile web add /root/phone-armor/payload/dsh-purge-community-1.6.91.tgz`。
