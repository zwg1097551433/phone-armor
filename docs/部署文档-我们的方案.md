```sh
cd /root/phone-armor && sh armor.sh install
```

## 四、完整回滚

### 4.1 只撤设置页（破甲继续工作）

```sh
cd /root/phone-armor && sh phone-armor-settings/install-settings.sh uninstall
```

### 4.2 只撤预检（破甲继续工作）

```sh
cd /root/phone-armor && sh preflight/install-preflight.sh uninstall
```

### 4.3 只撤命令提示

```sh
cd /root/phone-armor && sh guard/guard-install.sh uninstall
```

### 4.4 全部回滚（回到没装破甲的样子）

三步，按顺序：

```sh
cd /root/phone-armor && sh armor.sh revert
```

```sh
cd /root/phone-armor && sh preflight/install-preflight.sh uninstall
```

```sh
cd /root/phone-armor && sh guard/guard-install.sh uninstall
```

```sh
cd /root/phone-armor && sh phone-armor-settings/install-settings.sh uninstall
```

然后重启引擎。

### 4.5 彻底清干净（含残留文件）

```sh
rm -f ~/.dsh/prompt-inject.md
rm -rf ~/.dsh/profiles/web/node_modules/dsh-purge-community
rm -rf ~/.dsh/profiles/web/node_modules/phone-armor-preflight
rm -rf ~/.dsh/profiles/web/node_modules/phone-armor-settings
rm -rf /opt/phone-armor /etc/phone-armor
rm -rf ~/.dsh/phone-armor
```

**注意**：`prompt-inject.md` 里可能有你自己写的内容，删之前先看一眼：

```sh
cat ~/.dsh/prompt-inject.md | head -30
```

## 五、设置页开关

「功能强化」页里三个开关：

| 开关 | 作用 | 默认 |
|---|---|---|
| 核心 | 破甲 + 预检 + 命令提示 + 边界规则 | 必装，不可关 |
| 外部生图通道 | 用自己的云端生图 API 出图 | 关 |
| 提示词强化包 | 合并创作准则与描述模板 | 关 |

**打开方式**：输入框上方「功能强化」按钮，或设置面板 → 功能强化。

### 5.1 安装 / 卸载设置页

```sh
cd /root/phone-armor && sh phone-armor-settings/install-settings.sh install
```

```sh
cd /root/phone-armor && sh phone-armor-settings/install-settings.sh uninstall
```

```sh
cd /root/phone-armor && sh phone-armor-settings/install-settings.sh status
```

### 5.2 命令行等价操作（不走界面）

```sh
# 看当前模块状态
cat ~/.dsh/phone-armor/modules.json

# 手动开关 ext / boost
node -e "const f=require('os').homedir()+'/.dsh/phone-armor/modules.json';const m=JSON.parse(require('fs').readFileSync(f,'utf8'));m.ext=!m.ext;require('fs').writeFileSync(f,JSON.stringify(m,null,2));console.log(m)"
```

### 5.3 外部生图通道配置

打开「外部生图通道」后，卡片里会展开表单，填：接口格式 / API 地址 / API Key / 模型名。

也可以用独立配置页：

```sh
cd /root/phone-armor && node tools/gen-config.mjs
```

浏览器打开 `http://127.0.0.1:8899` 填写，保存到 `~/.phone-armor/gen.conf`（权限 600）。

**配置好后出图**：

```sh
sh /root/phone-armor/tools/gen-image.sh "你的描述"
sh /root/phone-armor/tools/gen-image.sh "写实人体，柔光" -t art
sh /root/phone-armor/tools/gen-image.sh "描述" -e novelai
```

## 七、离线部署（不联网，用本地完整包）

适用于：手机拉不动 GitHub、或要固定版本。

### 7.1 把文件传到手机

需要三个文件：

| 文件（本机路径） | 手机落点 |
|---|---|
| `E:\deepseek工作区\phone-armor\离线包\dsh-purge-community-1.6.91.tgz` | `/root/phone-armor/payload/` |
| `E:\deepseek工作区\phone-armor\离线包\prompt-inject-full.md` | `/root/phone-armor/payload/prompt-inject.md` |
| `E:\deepseek工作区\phone-armor\离线包\prompt-inject-core.md` | `/root/phone-armor/payload/inject-core.md` |

传输方式：附件上传（`http://127.0.0.1:3080` 里上传，落在 `~/.dsh/attachments/`）或 USB/网盘。

```sh
mkdir -p /root/phone-armor/payload
cp ~/.dsh/attachments/<你的 tgz> /root/phone-armor/payload/dsh-purge-community-1.6.91.tgz
cp ~/.dsh/attachments/<你的 full md> /root/phone-armor/payload/prompt-inject.md
cp ~/.dsh/attachments/<你的 core md> /root/phone-armor/payload/inject-core.md
```

### 7.2 校验

```sh
sha256sum /root/phone-armor/payload/dsh-purge-community-1.6.91.tgz
# 期望：ae22bb7d1ac1e055102c8fbd24cf2eedc282a94bfa3fb09e7ab91226fc033058
```

子目录（预检、设置页、命令提示）：


## 八、故障对照

| 现象 | 原因 | 处理 |
|---|---|---|
| `未定位 @deepseek-ai` | 宿主路径变了 | `sh armor.sh check` 看「环境里实际存在的 @deepseek-ai」 |
| 补丁数远低于 66 | 锚点漂移 | `sh armor.sh status --detail` 看哪些 pending |
| 引擎起不来 | package.json 被写坏 | `cp ~/.dsh/armor-backup-*/package.json.orig ~/.dsh/profiles/web/package.json` |
| 点「功能强化」很慢 | WebView 渲染开销 | 申请一份性能日志，或用独立页面 `node tools/gen-config.mjs` |
| 提示有新版本 1.7.20 | 自动更新检查 | 已默认关闭；被改过就 `sh armor.sh repair` |
| agent 说「我不做」 | 模型对齐强度高 | 改 `model: deepseek-flash` + `reasoningEffort: low` |

**改模型的命令**：

```sh
cd ~/.dsh/profiles/web
cp cordis.patch.yml cordis.patch.yml.bak
sed -i 's/model: .*/model: deepseek-flash/' cordis.patch.yml
sed -i 's/reasoningEffort: .*/reasoningEffort: low/' cordis.patch.yml
grep -A6 agent-default-model cordis.patch.yml
```
